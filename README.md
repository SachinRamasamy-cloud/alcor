# ALCOR

Anime and manga discovery with a private library and exact episode/chapter history. ALCOR does not host video or manga chapters.

This repository is being implemented from the owner's version 1.0 plans. See the [documentation index](docs/README.md) for scope, setup, evidence and outstanding release gates.

Start with the [local development guide](docs/engineering/development.md). The stack is React/TypeScript/Vite, FastAPI, PostgreSQL, Redis and Supabase Auth.

## Development status

Work is on `build/alcor-v1` in reviewable feature commits. A pushed branch is not a production release. Live catalogue rights, dedicated service configuration, independent engineering/security review and rendered editorial approval are release prerequisites.

Development resumed on 25 November 2026. [Handover and next tasks](docs/engineering/handover.md) describe the saved checkpoint. The complete roadmap is not yet implemented.
